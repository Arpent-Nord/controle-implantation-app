1. Quand utiliser l'outil

Après une implantation ou un levé de vérification (colonnes, semelles, murs, axes d'un bâtiment, bordures…) pour savoir si chaque point est conforme au plan, et produire un rapport à remettre au client ou au chantier.

Le plan et les points sont lus dans votre navigateur : rien n'est envoyé sur Internet. À l'ouverture, un exemple fictif est chargé pour vous exercer.

2. Fichiers nécessaires

BoutonFichierRemarques
Plan DXF…Plan théorique .dxfExporté de Civil 3D / AutoCAD, dans le même système de coordonnées que le levé.
Points levés….txt / .csvP,N,E,Z,D ou P,E,N,Z,D : choisissez l'ordre sous le nom du fichier. Plusieurs fichiers peuvent être ajoutés.
Ouvrir un dossier…Dossier enregistréReprend un contrôle déjà commencé (voir section 10).

× à côté d'un fichier le retire.

3. Les étapes en bref

  1. Ouvrir le plan DXF, puis les points levés.
  2. Vérifier les règles d'analyse (tolérances) du mandat.
  3. Onglet Codes : vérifier que chaque code du levé est associé au bon calque du plan et a le bon rôle.
  4. Regarder le plan : les points hors tolérance et douteux ressortent en couleur. Onglet Points pour la liste.
  5. Onglet Axes : Détecter les axes du plan pour exprimer les écarts par axe du bâtiment.
  6. Onglet Rapport : choisir les points, remplir l'en-tête, Aperçu du rapport, puis Télécharger (HTML).
  7. Enregistrer le dossier pour pouvoir y revenir.

4. Règles d'analyse

RéglageRôle
Tolérance en plan (mm)Écart horizontal maximal accepté : au-delà, le point est hors tolérance.
Tolérance en Z (mm)Écart vertical maximal accepté.
Rayon d'accroche sommet (mm)Si un coin du plan est à moins de cette distance, l'écart est mesuré au coin.
Douteux au-delà de (mm)Écart trop grand pour être une simple erreur d'implantation : le point est probablement associé au mauvais élément. À vérifier.
Doublons à moins de (mm)Deux points levés plus proches que cette distance sont signalés en double.

Méthode Auto : écart au coin si un sommet est dans le rayon d'accroche ; sinon écart perpendiculaire à la ligne (EC, positif à droite).

5. Codes du levé → calques du plan

Chaque code est associé automatiquement à un calque par son nom abrégé (8 caractères, comme Trimble). Pour chaque code :

  • Rôle : Implantation (contrôlé), Station, Référence / cible, Vérification (fermeture). Les stations et références ne sont pas contrôlées.
  • Méthode : Auto, Sommet (forcer l'écart au coin, pour un code de coins), Ligne (EC), ou Ignorer.
  • Calques : + calque… pour en ajouter, × pour en retirer.

Onglet Calques : afficher tous les calques du plan ou seulement ceux associés.

6. Lire le plan

Légende : Conforme, Hors tolérance, Association douteuse, Exclu, Non classé, Station, Référence / cible.

Vecteurs ×100 trace les écarts agrandis 100 fois, pour voir d'un coup d'œil le sens des erreurs. Numéros affiche les numéros de points ; Ajuster recadre ; 2D / 3D change la vue.

Sélection ▭ ou Maj + glisser sélectionne plusieurs points.

7. Onglet Points

Filtres : Tous, Contrôlés, Hors tol., Douteux, Doublons, Exclus, Non classés, Stations / réf., Liés à un axe, Au rapport.

Touchez une ligne pour localiser le point sur le plan et ouvrir sa fiche. Ajouter les … points affichés au rapport ajoute tout le filtre en cours.

En bas : moyenne, RMS et écart maximal en plan (sans les douteux), et Télécharger tous les points (CSV).

8. Onglet Axes

Détecter les axes du plan lit les axes du bâtiment ; Ajouter un axe (clic sur une ligne) pour en ajouter un.

Chaque point est lié à l'axe le plus proche dans chaque direction (au plus deux axes) : le rapport donne alors l'écart par rapport à l'axe 1, l'axe A, etc. Pour corriger : sélectionnez un point puis cliquez l'axe voulu sur le plan, ou Délier la sélection.

Exporter les axes (.json) / Importer des axes… pour réutiliser les mêmes axes au prochain contrôle du chantier.

9. Onglet Rapport

  1. Choisir les points : + Hors tolérance, + Tous les contrôlés, + Sélection (ou Vider).
  2. Remplir l'en-tête : Projet, N° de dossier, Client, Lieu, Préparé par, Objet, Remarques.
  3. Choisir les sections : par axe, par point, croquis, coordonnées, stations et références.
  4. Aperçu du rapport, puis Télécharger (HTML) ou CSV du rapport.

Le fichier HTML s'ouvre dans n'importe quel navigateur : Imprimer → Enregistrer en PDF pour l'archiver. Le CSV utilise le point-virgule et la virgule décimale (Excel en français).

10. Enregistrer le travail

Enregistrer le dossier sauvegarde le plan, les points, les associations, les axes et le rapport. Rangez-le dans le dossier du mandat (jamais sur GitHub). Ouvrir un dossier… pour reprendre.

Les plans et levés de mandat ne doivent jamais être déposés dans un dépôt public. L'outil est public, vos données restent sur votre poste.

11. Questions fréquentes

Beaucoup de points « douteux »

Vérifiez l'onglet Codes : le code est peut-être associé au mauvais calque, ou le plan et le levé ne sont pas dans le même système de coordonnées.

Les écarts ne sont pas mesurés au coin

Augmentez le rayon d'accroche sommet ou choisissez la méthode Sommet pour ce code.

L'outil affiche une ancienne version

Rechargez la page avec Ctrl+F5.
